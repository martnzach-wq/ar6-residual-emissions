# Raw data (not under version control)

Place the AR6 Scenarios Database v1.1 files here after downloading them from the
AR6 Scenario Explorer hosted by IIASA (login required, licence must be accepted):

- `AR6_Scenarios_Database_World_v1.1.csv` (unzipped)
- `AR6_Scenarios_Database_metadata_indicators_v1.1.xlsx`

The AR6 licence restricts redistribution of substantial parts of the database,
so these files are excluded from Git (see `.gitignore`).
